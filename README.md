# CarryGo Influencer Homepage

CarryGo / Carry AI K-fashion social launcher homepage.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Local Preview

```bash
npm run dev
```

Static export:

```bash
npm run build
npx serve out
```
